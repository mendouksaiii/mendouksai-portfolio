## Featured Flagship Production Builds

1. **Redline Rider (Endless 3D Physics Web Game & Reddit App)**
   - *Stack:* TypeScript, Three.js, Rapier 3D WASM, Custom GLSL Shaders, WebAudio API, Reddit Devvit, Vercel.
   - *Engine:* Single-file, zero-dependency 3D downhill survival biking game running deterministic procedural terrain generation via seeded `mulberry32` noise. Self-monitoring Adaptive Quality Engine maintaining a strict sub-21ms budget for guaranteed 60 FPS.
   - *Live:* [redline-rider.vercel.app](https://redline-rider.vercel.app) · [GitHub](https://github.com/mendouksaiii/downhill-rush)

2. **SENTINEL (On-Chain AI Policy Firewall for Autonomous Agents)**
   - *Stack:* Solidity, Mantle Sepolia (5003), EIP-712 Typed Signatures, Claude 3.5 Sonnet, WebSockets.
   - *Architecture:* Mantle Turing Hackathon finalist. Automated spending governance firewall where AI decisions serve as cryptographic preconditions. Single-use EIP-712 authorizations verified on-chain by `SentinelVault.sol` with immutable `SentinelRegistry.sol` audit trail.
   - *GitHub:* [Natural-language-policy-engine](https://github.com/mendouksaiii/Natural-language-policy-engine.-)

3. **M-Fi Underwriter (Autonomous Credit & Liquidity Bureau)**
   - *Stack:* Sui Move, Walrus Protocol, TypeScript, Groq LLaMA 3.1, Tether WDK, Aave V3.
   - *Architecture:* Galáctica Hackathon entry. Autonomous on-chain underwriting engine evaluating agent liquidity and counterparty risk for uncollateralized micro-lending.
   - *Live:* [m-fi-underwriter.vercel.app](https://m-fi-underwriter.vercel.app) · [GitHub](https://github.com/mendouksaiii/m-fi-underwriter)

4. **Banterbot & Kite (Multimodal Autonomous iMessage Agents)**
   - *Stack:* TypeScript, Photon Spectrum (`spectrum-ts`), Google Gemini 2.5 Flash, Groq (Llama 3.3), Docker, Railway.
   - *Features:* Dual-brain architecture with automatic zero-downtime failover, native 3-dot typing indicators, Apple tapbacks, bubble effects, and 3-round roast battle state machines.
   - *GitHub:* [banterbot](https://github.com/mendouksaiii/banterbot) · [kite](https://github.com/mendouksaiii/kite)

5. **Agent Wallet Runtime & WalletSecure**
   - *Stack:* React, TypeScript, Ethers.js, Viem, WebSockets.
   - *Features:* Autonomous agent execution runtime and a connection pipeline killing React cold-start state drops in Web3 dApps.
   - *Live:* [walletsecure-8ilj.vercel.app](https://walletsecure-8ilj.vercel.app/) · [GitHub](https://github.com/mendouksaiii/agent-wallet-runtime)

## Design System & Guardrails

- **Archetype:** Swiss International Typography & Neo-Modernist Bento Grid.
- **Color Palette:** Deep Obsidian (`#080A0F`), Surface Card (`#121622`), Cyber Cyan (`#00F0FF`), Signal Emerald (`#00FF85`), Electric Purple (`#B026FF`).
- **Typography:** Display headlines in **Space Grotesk**, interface text in **Inter**, metrics & code in **JetBrains Mono**.
- **Guardrails:**
  - Strictly no emoji icons — 100% inline SVG iconography (Lucide / Heroicons).
  - WCAG AA contrast compliant (>4.5:1 on all text).
  - Zero layout shift on interactive hover states.
  - Fully responsive across 375px (mobile), 768px (tablet), 1024px (laptop), and 1440px (desktop).
  - Web Audio API haptic sound synthesizer with persistent mute toggle and zero external audio asset requests.
